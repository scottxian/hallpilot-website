How it works

Simple flow. Clear accountability.

01

Student requests a pass

The student selects a destination and submits a request from the room page.

02

Hall Pilot manages the queue

If a pass is available, Hall Pilot can start it immediately. Otherwise, students join a destination-specific waiting list, see their place in line, and select Go when they’re eligible. Teachers don’t need to manage each request, but approval can still be required for designated destinations.

03

Return is recorded automatically

When the student returns, the pass is closed and included in reports and activity history.
