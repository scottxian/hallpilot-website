Hall Pilot — Marketing Website
==============================

Repository: scottxian/hallpilot-website
Intended public address: https://hallpilot.net/
Application address: https://app.hallpilot.net/

This is the separate public website for Hall Pilot. The application is managed in the separate scottxian/wusd-hall-pass repository.

Deployment
----------
This repository contains a GitHub Pages-compatible static website.
Deploy from branch main and folder /(root) under Settings > Pages.
Use hallpilot.net as the custom domain. Do not replace the custom domain on the existing application repository.

Branding
--------
The page uses Hall Pilot's hallway / paper-airplane mark. SVG assets are included for the website and favicon. A higher-resolution approved logo can be added in the future at assets/hall-pilot-logo.png and assets/hall-pilot-icon.png; the page includes SVG fallbacks.

The PNG favicon and preview assets in the original downloadable design ZIP have not been committed yet. The SVG favicon works in modern browsers. Do not rely on missing PNG assets until uploaded.

Privacy & security
------------------
Do not publish student information, PINs, Supabase secret/service-role keys, or other private credentials in this public repository.
